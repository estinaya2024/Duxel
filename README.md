# Duxel Studio

🌐 **Live:** [https://duxel-j374.vercel.app](https://duxel-j374.vercel.app)

A color palette tool I built for generating and exploring design themes. You can upload any image and it'll pull out the dominant colors, or just search a color name/hex and build from there.

## What it does

- Upload an image → extracts the top colors and maps them to design roles (primary, secondary, accent, etc.)
- Search by color name, hex, RGB, or CMYK
- Live previews in 4 mockup layouts (landing page, dashboard, mobile app, product grid)
- Dark mode generator, undo/redo, save palettes, export as CSS / JSON / SVG

## Running it locally

```bash
npm install
npm run dev
```

## Stack

React + TypeScript, Vite, Framer Motion, Chroma.js, Lucide icons
